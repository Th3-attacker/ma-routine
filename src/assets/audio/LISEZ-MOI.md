# Enregistrements des athkar

Déposer ici les fichiers du récitant, avec les noms donnés dans `ENREGISTREMENTS.md` (racine, `pnpm audio`) :

- `athkar/matin-01.mp3`, `athkar/soir-03.mp3`… (séries d'athkar)
- `douas/reveil-01.mp3`, `douas/voyage-02.mp3`… (invocations)

Un bouton ▶ apparaît dans l'app pour chaque fichier présent. Formats : `.mp3` (conseillé), `.m4a` ou `.ogg`.
